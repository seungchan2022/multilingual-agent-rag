# 3 세기: 대조 상태 (status)

숫자는 confirm.json에서 계산했다. 맞은 것 = read_ok가 true이고 truth가 "그 언어에만"인 것. 채운 것 = read_ok와 truth가 둘 다 채워진 것(모델 시험 차례에서는 맞은 후보가 ask까지 채워야 채운 것). 두 언어 쪽은 판정에 쓰지 않는다(결정 "3 세기에서 두 언어 주제 쪽의 필요한 수(18)는 통과 판정에서 빼고"). 표의 맞은 수는 어느 차례에서 채웠든 센다. 쪽 몫과 모델 시험 몫은 차례의 앞에서부터 빈틈없이 채운 부분의 맞은 수로 멈춘다. 모델 시험 값은 그 부분에서 맞은 것 가운데 ask가 "하나"인 것이고(이미 채운 판정도 그 부분에 들면 쓴다), 모델 시험 몫의 맞은 수는 이 모델 시험 값의 수다.
