# 첫 묶음(한국어 질문·한국어 문서) 사용자 판정

후보마다 사용자가 원문과 대조한 결과를 적는다. Claude는 사용자의 판정이 끝난 뒤 같은 후보를 원문과 다시 대조해, 이 기록과 견줘 놓친 것을 센다(`decisions/common.md` 2026-10-15). 그래서 판정을 마칠 때까지 Claude에게 후보 내용의 맞고 틀림을 묻지 않는다. 절차를 묻는 것은 된다.

적는 법: 확인한 칸은 `[ ]`를 `[x]`로 바꾼다. 확인하지 않은 칸은 그대로 둔다(비워 둔 것도 기록이다). 판정은 채택·수정·폐기 가운데 하나를 남긴다. 근거 구절이 원문에 글자 그대로 있는지와 개수·형식은 후보 검사 프로그램이 이미 봤다.

## c-001

- [ ] 근거 구절만 읽고 정답이 나온다 (조건·단위 포함)
- [ ] 정답이 하나로 정해진다
- [ ] 같은 문서 안에 다른 값이 없다 (`Cmd+F`)
- [ ] 같은 언어의 다른 문서에 다른 값이 없다 (VS Code 폴더 찾기 `Cmd+Shift+F`)
- [ ] 영어 문서 14개에 같은 사실이 없다 (같은 도시의 영어 문서는 번역문 읽기, 그 밖은 찾을 말로 폴더 찾기)
- [ ] `required_facts`가 빠짐없고 군더더기 없다
- [ ] 유형이 맞다
- 판정: 채택 / 수정 / 폐기
