# 여러 문서 연결 질문의 재료 (2026-10-15)

`research_notes/stage2_fact_count/checked_markdown.json`에서 상태가 `통과` 또는 `통과(읽고 확인)`이고 `excluded`가 없는 사실 187개를 종류(`kind`)별로 모아, 문서 둘 이상의 사실을 합쳐야 답이 나오는 조합을 AI가 골랐다. 연결형(K9, K10)은 2단계 사실 목록 밖의 관광공사 글과 포털 표를 AI가 읽고 찾았다. 반대 언어 문서에 없는지는 사실 목록의 판정(2단계)과, 연결형은 AI가 영어 문서를 grep한 것까지다. 같은 언어의 다른 문서와 값을 견주는 확인(`decisions/stage3.md` 2026-10-15)은 아직 하지 않았다. 질문을 만들 때 한다.

묶음: 두 = 두 언어 도시, 한 = 한국어 도시, 영 = 영어 도시.
