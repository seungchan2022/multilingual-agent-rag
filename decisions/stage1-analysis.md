# 결정: 1단계 집계와 분석

1단계(평가의 틀)에서 정한 것 가운데 여러 답의 결과를 세고 비교하고 리포트에 적는 방법(도구 호출, 언어별 결과, 흔들리는 범위와 비교, 오류 유형 빈도표, 심화 분석 사례, 응답 시간)을 적는다. 새 결정은 표 아래에 추가하고, 바뀐 결정은 지우지 않고 새 줄로 적는다.
