# 결정: 3단계 질문

3단계(질문)에서 정한 것을 적는다. 질문을 대조하는 방법, 질문 수의 배분, 질문을 만드는 규칙, 형식 검사, 최종 평가용의 보관이다. 새 결정은 표 아래에 추가하고, 바뀐 결정은 지우지 않고 새 줄로 적는다.
